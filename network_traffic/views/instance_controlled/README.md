# Instance-controlled traffic

This view normalizes instance and session information while retaining explicit model identifiers. Packet lengths, directions, relative timing, and connection boundaries are preserved.

This directory contains 84 TAR archives of connection PCAPs. It covers the same 40,781 samples, 270,289 connections, and 3,190,239 packets as the other two views. Use the [shared indices and loading example](../README.md) to locate and compare corresponding connections.
